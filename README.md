# Приватный Telegram Mini App «Наш Уголок» ❤️

Уютное, безопасное и интерактивное мини-приложение для Telegram, созданное специально для двоих.

- **Zero-Backend**: работает полностью на клиенте (Static Frontend), хостится бесплатно на **GitHub Pages**.
- **Приватность и Безопасность**: доступ строго по Telegram ID (`initDataUnsafe.user.id`). Никакие IP-адреса не собираются и не логируются на сторонних серверах.
- **Telegram Bot Push-уведомления**: бот автоматически отправляет уведомление на телефон партнеру, если его нет в сети при нажатии действий («Кусь», «Поцелуй», «Срочный созвон», «Обидка» и др.)!
- **Синхронизация через Telegram**: состояние питомца, баночек любви и записок хранится в **Telegram Cloud Storage** + резервный кэш `localStorage`.
- **Тактильный отклик**: поддержка **Telegram Haptic Feedback** (уникальные вибро-паттерны под каждое действие).

## 📱 Возможности приложения

### 1. 10 Интерактивных действий и сигналов (с Push-уведомлениями)
Вместо одного объятия теперь доступен целый спектр живых эмоций с полноэкранными эффектами и тактильной вибрацией:
1. 💋 **«Чмок / Поцелуй»** — экран покрывается отпечатками поцелуев с нежным вибро.
2. 🤗 **«Крепкие обнимашки»** — глубокое согревающее объятие.
3. 💆‍♀️ **«Погладить по головке»** — ласка и забота, когда партнер устал(а).
4. 😼 **«Кусь!»** — игривый кусь за щёчку с вибро-щелчком.
5. 🪶 **«Пощекотать»** — экран дрожит, серия быстрых импульсов щекотки.
6. 🥺 **«Дуюсь / Маленькая обидка»** — дождевое облачко и сигнал, что нужно внимание и сладости.
7. 🧸 **«Хочу на ручки»** — просьба укутать пледом и пожалеть.
8. 🥱 **«Сонный кусь / Засыпаю»** — звёзды, месяц и пожелание сладких снов.
9. ✨ **«Ты справишься!»** — мощный салют поддержки перед важным делом.
10. 🚨 **«Срочно нужен созвон!»** — пульсирующая сирена, когда безумно соскучились.

> 📲 **Если партнер сейчас не в приложении**, бот присылает ему личное Push-сообщение в Telegram:  
> *«💋 Саша отправил(а) тебе нежный поцелуй прямо в щёчку!»* или *«🚨 ВНИМАНИЕ! Алина просит срочный созвон!»*

### 2. «Баночки любви» (Love Jars)
- Две стеклянные баночки (твоя и её) с пробками, бликами и плавающими сердечками.
- **Правило пары**: ты наполняешь **только её баночку** сердечками, а она — **только твою**! Свою наполнять нельзя.
- Внутрь баночки можно вложить нежное признание (записка-послание в бутылке).

---

### 3. «Сердца в унисон» (Ритм наших сердец)
- Настоящая физическая пульсация двух сердец (Его и Её) с реальной частотой BPM.
- 4 уровня ритма тоски:
  * ☕ **60 BPM** — *«Спокойно / Рядом в мыслях»*
  * 💌 **90 BPM** — *«Трепет / Вспоминаю с улыбкой»*
  * 🥺 **125 BPM** — *«Скучаю / Очень не хватает тебя»*
  * 🔥 **160 BPM** — *«Зашкаливает / Сердце выскакивает из груди!»*
- Каждый управляет своим сердечным ритмом.
- **Магия унисона**: если ваши ритмы совпали — карточка загорается золотистым сиянием, вылетает салют из сердец и появляется статус *«✨ Ваши сердца бьются в один такт!»*.

---

### 4. «Наш Питомец» (Тамагочи для двоих)
- Анимированный кавайный питомец (дышит, моргает, подпрыгивает от поглаживаний).
- **Кормление 🍖**: печенька, десерт, клубника, пицца, бабл-ти.
- **Игра 🎾**: мини-игра «Ловля сердечек» на 12 секунд.
- **Купание 🛁**: мыльные пузыри, которые можно лопать тапом.
- **Гардероб 👒**: шапочка, шарфик, очки-сердечки, бантик, корона.
- **Прогулка 🌳**: выход в парк на свежий воздух.

## ⚙️ Настройка приложения под вашу пару

Все персональные настройки находятся в одном файле: `js/config.js`.

### 1. Узнайте ваши Telegram ID
- Напишите боту [@userinfobot](https://t.me/userinfobot) в Telegram (и вы, и ваша половинка). Он пришлет ваш цифровой ID (например, `123456789`).

### 2. Создайте бота в @BotFather и получите токен
1. Откройте в Telegram бота [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot` и задайте имя и username (например, `OurCornerLove_bot`).
3. Скопируйте полученный **HTTP API Token** (вида `1234567890:ABCdefGHI...`).
4. Настройте кнопку меню для открытия приложения:
   - Отправьте `/setmenubutton` ➔ выберите вашего бота ➔ введите текст `Наш Уголок ❤️` ➔ укажите ссылку на ваш GitHub Pages.
5. **Важно**: И вы, и ваша половинка должны **один раз нажать `/start`** в созданном боте, чтобы он мог присылать вам Push-уведомления, когда вы не в приложении!

### 3. Отредактируйте `js/config.js`
Откройте `js/config.js` и вставьте данные:

```javascript
// Токен бота от @BotFather (для отправки уведомлений партнеру)
BOT_TOKEN: "ВАШ_ТОКЕН_ОТ_BOTFATHER",

// Дата начала отношений
RELATIONSHIP_START_DATE: "2024-01-01T00:00:00",

// Белый список (только ваши два ID)
ALLOWED_USERS: [
  {
    id: 123456789,        // Твой Telegram ID
    name: "Саша",
    partnerName: "Алина",
    role: "him",
    avatar: "👨‍💻",
    loveLabel: "Баночка Его любви"
  },
  {
    id: 987654321,        // Её Telegram ID
    name: "Алина",
    partnerName: "Саша",
    role: "her",
    avatar: "🌸",
    loveLabel: "Баночка Её любви"
  }
],
```

## 🚀 Бесплатный деплой на GitHub Pages

1. Загрузите файлы репозитория на [GitHub](https://github.com).
2. Зайдите в **Settings** репозитория ➔ вкладка **Pages**.
3. В **Build and deployment** выберите: `Deploy from a branch` ➔ ветка `main` (или `master`) ➔ папка `/ (root)`.
4. Нажмите **Save**. Ссылка на сайт будет готова через 1–2 минуты!

## 🛠️ Тестирование в обычном браузере (Dev-режим)
При открытии `index.html` прямо на компьютере в браузере в правом верхнем углу активна панель **DEV MODE**: вы можете переключаться между пользователями («Саша» / «Алина»), чтобы проверить отправку всех 10 действий и работу баночек с обеих сторон!
